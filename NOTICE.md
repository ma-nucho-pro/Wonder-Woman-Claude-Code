# Design notice

Wonder Woman was created from requirements supplied by the user, including: explicit uncertainty labels, source verification, anti-complacency, correction of false premises, numerical checking, web-first verification for public facts when available, and a repeated pre-release review loop.

The supplied `obra/superpowers` archive was used as an architectural reference for skill organization and for ideas such as isolated subagents, parallel review, independent re-review, evidence-gated completion, and bounded correction loops. Wonder Woman does not copy Superpowers source code and uses its own prompts, role names, policies, and output contracts.
