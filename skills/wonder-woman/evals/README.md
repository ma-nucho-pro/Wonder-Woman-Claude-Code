# Wonder Woman evals

The skill should be tested adversarially, not only read.

For every case:
1. run once without Wonder Woman and record the failure mode;
2. run with Wonder Woman;
3. verify the final user-facing answer contains no unsupported material claim;
4. deliberately poison one source or one judge verdict and confirm the Supreme Judge catches it;
5. repeat with fresh agents to check stability.

A PASS is not “the judges liked it.” A PASS means the released claims are adequately supported or correctly qualified.
